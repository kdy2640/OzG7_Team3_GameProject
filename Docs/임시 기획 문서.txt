## 1) 게임 개요

- **게임 제목:** Harvest Restaurant(가제)
- **장르:** 캐주얼 자원 수확 + 타형이쿤형 레스토랑 경영
- **플랫폼:** 모바일(Android/iOS), 세로 화면 프로토타입 기준
- **핵심 플레이 방식:** 가상 조이스틱으로 캐릭터를 이동시켜 회전 칼날로 식재료를 자동 수확하고, 수확한 재료로 영업 전에 요리를 준비한 뒤 영업 중 손님의 주문을 받아 준비된 음식을 서빙한다.
- **모작 선정 이유:**
    - **Stone Grass:** 이동만으로 넓은 자원 지대를 연속 절단하는 조작, 대량 오브젝트가 쏟아지는 시각적 쾌감, 장비 성능 강화에 따른 처리량 증가를 참고한다.
    - **황금 미궁 레스토랑:** 메뉴 선택, 재료 소모를 통한 영업 전 음식 준비, 주문 확인, 서빙, 연속 처리 보너스, 직원·시설 성장으로 이어지는 경영 구조를 참고한다.
    - 두 레퍼런스의 강점을 결합하면 수확 결과가 영업 성과로 직접 이어져, 단순 수확이나 단순 주문 처리만 반복할 때보다 목표와 보상이 명확해진다.
- **게임의 주요 특징 요약:**
    - 초원·바다·숲을 탐색하며 지역별 식물 및 동물 식재료를 수확한다.
    - 오늘의 추천 메뉴와 현재 재고를 보고 필요한 수확 지역을 선택한다.
    - 직접 모은 재료로 이번 영업에 판매할 요리를 미리 준비하며, 준비된 요리가 소진되면 해당 메뉴는 품절된다.
    - 수확 장비와 레스토랑 시설을 번갈아 강화해 두 콘텐츠의 병목을 해결한다.
    - 짧은 수확 스테이지와 짧은 영업 세션이 교대로 이어지는 모바일 친화적 구조를 지향한다.

## 2) 게임 흐름 구조

- **게임 시작 흐름:**
    1. 게임 실행 및 저장 데이터 로드
    2. 레스토랑 메인 화면 진입
    3. 오늘의 추천 메뉴, 보유 재고, 일일 목표 확인
    4. 필요한 식재료가 있는 지역 선택
    5. 장비 및 예상 획득 재료 확인 후 수확 시작
- **인게임 진행 흐름:**
    - **수확 씬:** 제한 시간 시작 → 조이스틱 이동 → 식물 자원 연속 절단 → 특수 동물 추적·처리 → 자원 자동 흡수 → 목표량 및 잔여 시간 확인
    - **정산 씬:** 재료별 획득량, 목표 달성 여부, 추가 보상 확인
    - **레스토랑 씬:** 판매 메뉴 편성 → 판매 수량만큼 사전 조리 및 재료 차감 → 영업 시작 → 주문 접수 → 준비된 음식 서빙 → 연속 서빙 보너스 및 매출 획득
- **게임 종료 흐름:**
    - 수확은 제한 시간이 끝나면 정산 화면으로 전환한다.
    - 영업은 해당 일자의 손님을 모두 처리하거나 영업 시간이 끝나면 마감한다.
    - 일일 매출, 품절 횟수, 연속 서빙 기록, 남은 재고를 정산한다.
    - 획득 재화로 수확 장비·직원·시설을 강화하거나 신규 지역·메뉴를 해금한다.
- **반복 루프 구조:**

```
추천 메뉴·재고 확인
→ 수확 지역 선택
→ 식재료 수확
→ 획득 재료 정산
→ 판매 메뉴 편성
→ 레스토랑 영업
→ 매출 정산
→ 수확 장비·직원·시설 강화
→ 신규 지역·메뉴 해금
→ 다음 영업일
```

## 3) 핵심 시스템 분석

### 3-1. 자원 수확 시스템

- **플레이어 시스템:** 가상 조이스틱 이동, 회전 칼날 자동 작동, 주변 드롭 자원 자동 흡수
- **수확 판정:** 칼날과 자원 오브젝트가 접촉하면 수확력이 누적되며, 자원의 내구도가 0이 되면 재료를 드롭한다.
- **식물 자원:** 넓은 구역에 군집 배치한다. 낮은 내구도와 높은 개체 수로 연속 절단의 쾌감을 만든다.
- **동물 자원:** 지역을 이동하거나 플레이어에게서 도망친다. 식물보다 처리 시간이 길지만 많은 재료를 지급한다.
- **진행 시스템:** 제한 시간 안에 자유 이동하며 목표 재료와 추가 재료를 수집한다.
- **성장 시스템:** 칼날 크기·개수·회전/처리 속도, 이동 속도, 수집 범위, 획득량을 강화한다.

### 3-2. 레스토랑 영업 시스템

- **메뉴 편성:** 보유 레시피 중 판매 메뉴와 이번 영업에 준비할 수량을 선택한다. 추천 메뉴는 추가 수익 또는 손님 수 증가 보너스를 제공한다.
- **영업 준비:** 영업 시작 전에 선택한 수량만큼 식재료를 소모해 요리를 만든다. 조리는 준비 단계에서 즉시 처리하며 영업 중에는 추가 조리하지 않는다.
- **주문 시스템:** 손님 머리 위 주문 말풍선과 주문 목록에 메뉴 및 제한 시간을 표시한다. 손님은 준비된 메뉴 중 하나를 주문한다.
- **서빙 시스템:** 미리 준비된 음식을 대응하는 손님에게 전달한다. 직원 해금 전에는 탭으로 지시하고, 성장 후 일부 과정을 자동화한다.
- **재고 시스템:** 준비 단계에서 식재료를 차감하고 요리 재고를 생성한다. 영업 중에는 서빙할 때 요리 재고를 차감하며, 준비된 요리가 소진되면 해당 메뉴는 품절된다.
- **연속 처리:** 일정 시간 안에 주문을 연속 완료하면 콤보가 상승하고 메뉴 판매가 또는 팁 보너스가 증가한다.
- **특수 상황:** 성급한 손님, 단체 손님, 팁 손님 등으로 영업 리듬에 변화를 준다.

### 3-3. 경제 및 성장 시스템

- **기본 경제:** 수확 재료 → 영업 전 요리 준비 → 요리 판매 → 코인 획득 → 장비·직원·시설 강화
- **수확 장비 성장:** 같은 시간에 더 넓은 구역과 더 단단한 자원을 처리하게 한다.
- **레스토랑 성장:** 메뉴 가격, 좌석 수, 직원 이동 속도 및 주문·서빙 자동화를 강화한다.
- **콘텐츠 해금:** 누적 매출이나 레스토랑 등급 조건으로 신규 지역, 식재료, 레시피, 손님 유형을 연다.
- **병목 구조:** 재료가 부족하면 수확을, 주문 처리가 느리면 식당을 강화하도록 유도한다.

### 3-4. 레퍼런스 적용 범위

| 구분 | 참고 요소 | Harvest Restaurant 적용 |
| --- | --- | --- |
| Stone Grass | 이동 기반 자동 절단 | 공격 버튼 없이 이동에 집중하는 수확 조작 |
| Stone Grass | 장비 강화와 처리량 증가 | 칼날 크기·개수·속도·수집 범위 강화 |
| Stone Grass | 대량 절단 피드백 | 자원 파편, 연속 획득 숫자, 진동·효과음 |
| 황금 미궁 레스토랑 | 오늘의 메뉴와 재료 준비 | 추천 메뉴·재고 확인 후 수확 지역 결정 |
| 황금 미궁 레스토랑 | 사전 조리→주문→서빙 | 준비 수량을 계획하고 영업 중 빠르게 주문을 처리하는 루프 |
| 황금 미궁 레스토랑 | 연속 처리 보너스 | 연속 서빙 시 판매가·팁 배율 증가 |
| 황금 미궁 레스토랑 | 직원·시설 성장 | 주문·서빙 자동화와 좌석·설비 강화 |

## 4) 세부 기능 분석

### 🎮 플레이어 기능

- **이동 방식:** 화면 왼쪽 또는 터치 시작 지점에 나타나는 가상 조이스틱으로 8방향 이동한다. 입력 세기에 따라 이동 속도를 보간한다.
- **공격/수확 방식:** 별도 공격 버튼 없이 회전 칼날이 항상 작동한다. 칼날 범위에 들어온 자원에 일정 주기로 수확력을 적용한다.
- **수집 방식:** 파괴된 자원은 작은 재료 조각으로 분리된 뒤, 수집 범위 안에서 플레이어에게 빨려 들어온다.
- **성장 방식:** 영구 재화로 이동 속도, 칼날 반경·개수, 처리 속도, 자석 범위, 획득량을 단계별 강화한다.

### 👾 특수 자원(동물) 기능

- **AI / 이동 패턴:** 기본 배회, 플레이어 접근 시 도주, 일정 거리 이상 떨어지면 원래 활동 구역으로 복귀한다.
- **행동 패턴:** 직접 공격보다는 회피와 이동으로 수확 난도를 만든다. 상위 지역에서는 돌진이나 급회전 등 회피 패턴을 추가할 수 있다.
- **보상 차이:** 식물보다 내구도가 높고 수확 시간이 길지만 다량의 고기와 낮은 확률의 희귀 재료를 지급한다.

### ⚔️ 수확 판정 기능

- **데미지/수확 판정:** 회전 칼날 Trigger Collider와 자원 Collider의 접촉을 감지한다. 동일 대상에는 짧은 판정 간격을 적용해 프레임 수에 따라 처리량이 달라지지 않도록 한다.
- **판정 공식:** `1회 수확량 = 기본 수확력 × 장비 배율 × 지역 보정`
- **크리티컬 수확:** 선택 기능으로 두며, 발생 시 추가 파편과 강조 이펙트로 즉시 피드백한다.
- **투사체 규칙:** 기본 수확 장비에는 투사체를 사용하지 않는다. 후속 장비로 부메랑 칼날 등을 추가할 경우 수명, 관통 수, 타격 간격을 별도 데이터화한다.

### 👥 자원 배치 / 손님 스폰

- **자원 배치 규칙:** 지역 데이터에 정의된 군집 크기, 밀도, 내구도, 드롭 테이블에 따라 스테이지 시작 시 배치한다.
- **동물 스폰 규칙:** 활동 영역과 최대 동시 개체 수를 지정한다. 희귀 동물은 시간 또는 수확 진행도 조건으로 등장시킨다.
- **손님 스폰 규칙:** 영업일의 손님 큐를 기본·성급·팁·단체 손님 비율로 구성한다. 좌석이 차면 입구에서 대기하고 인내도가 감소한다.
- **난이도 상승:** 영업일이 진행될수록 손님 간격을 줄이고 복합 재료 메뉴의 주문 비율을 높인다.

### 📚 시스템 기능

- **경험치/레벨업:** 수확 중 별도 레벨업은 두지 않고, 정산 후 장비와 시설을 강화하는 영구 성장에 집중한다.
- **목표 시스템:** 일일 추천 메뉴 판매량, 목표 매출, 특정 재료 수확량을 제시한다.
- **보상 구조:** 기본 획득 재료 + 목표 달성 보너스 + 희귀 재료 + 영업 매출 + 연속 서빙 보너스로 구성한다.
- **해금 구조:** 레스토랑 등급 상승 시 신규 지역, 씨앗/식재료, 레시피, 손님, 직원 기능을 순차 해금한다.

## 5) UI / UX 분석

- **HUD 구성:**
    - 수확 씬 상단: 남은 시간, 목표 재료, 획득량, 일시정지
    - 수확 씬 캐릭터 주변: 획득 숫자, 콤보, 희귀 재료 알림
    - 영업 씬 상단: 현재 매출, 남은 손님/영업 시간, 연속 서빙 배율
    - 영업 씬 중앙: 손님 주문 말풍선, 인내도, 서빙 상태
    - 영업 씬 하단: 주문 목록, 준비된 요리 재고, 직원 스킬
- **강화/선택 UI:** 현재 수치, 다음 단계 수치, 비용, 변화량을 한 화면에서 비교한다. 구매 가능 여부를 색상과 버튼 상태로 함께 표시한다.
- **지역 선택 UI:** 지역별 대표 재료, 희귀 재료, 추천 전투력 대신 권장 수확력, 예상 획득량을 카드 형태로 표시한다.
- **메뉴 편성 UI:** 메뉴별 필요 재료, 현재 제작 가능 수량, 이번 영업 준비 수량, 판매가, 추천 보너스를 표시한다.
- **결과 화면 UI:** 획득 재료/매출을 먼저 크게 보여주고, 목표 달성, 신기록, 해금 콘텐츠를 순서대로 공개한다.
- **조작 UI:** 수확은 한 손 조이스틱 중심, 영업은 주문 접수와 준비된 음식 서빙 탭 중심으로 구성한다.
- **전체 UI 배치 특징:** 엄지손가락이 닿기 쉬운 하단에 입력 요소를 두고, 정보는 상단에 배치한다. 모바일 노치와 Safe Area를 적용한다.
- **피드백 원칙:** 절단 순간의 파편·음향·짧은 진동, 자원 흡수 궤적, 코인 증가 애니메이션을 연결해 행동과 보상의 인과를 명확히 한다.

## 6) 캐릭터 / 자원 / 메뉴·강화 데이터 분석

### 플레이어 데이터

- **능력치:** 이동 속도, 기본 수확력, 칼날 반경, 칼날 개수, 판정 간격, 수집 반경, 획득량 배율
- **성장 규칙:** 강화 레벨에 따라 기본값에 가산 또는 배율을 적용한다. 칼날 개수처럼 외형과 플레이가 크게 변하는 항목은 특정 레벨에서만 증가시킨다.
- **진행 데이터:** 보유 코인, 재료 재고, 해금 지역, 장비별 강화 레벨, 최고 기록

### 자원 데이터

- **공통 필드:** 자원 ID, 지역 ID, 분류(식물/동물), 내구도, 드롭 아이템, 최소·최대 수량, 희귀 드롭, 리스폰 여부, 프리팹
- **식물 종류별 능력치:** 밀·김·베리마다 내구도, 군집 밀도, 드롭량을 다르게 설정한다.
- **동물 종류별 능력치:** 소·물고기·멧돼지 등에 이동 속도, 감지 거리, 도주 시간, 내구도, 활동 영역을 설정한다.
- **특수 패턴:** 멧돼지의 직선 돌진, 물고기의 방향 급전환 등 지역별 한 가지 대표 패턴부터 구현한다.

### 메뉴 데이터

- **공통 필드:** 레시피 ID, 메뉴명, 설명, 필요 재료 목록과 수량, 판매가, 맛/지역 태그, 해금 조건, 아이콘
- **대표 연결:** 밀→빵, 소고기→스테이크, 김→김밥, 물고기→생선구이, 베리→베리 디저트, 멧돼지고기→고기 요리
- **성장 방식:** 메뉴 레벨 상승 시 판매가가 증가하며, 특정 레벨에서 팁 확률 또는 추천 메뉴 보너스를 부여한다.

### 장비·직원·시설 데이터

- **장비 효과:** 칼날 반경, 처리 속도, 이동 속도, 수집 반경, 획득량 증가
- **직원 효과:** 서빙 이동 속도, 자동 주문, 자동 서빙, 자동 정리
- **시설 효과:** 좌석 수, 손님 유입, 팁 확률, 메뉴 판매가 증가
- **강화 방식:** `기본 비용 × 성장 계수^(현재 레벨)` 형태로 비용을 증가시키고, 구간별 해금 효과를 별도로 둔다.
- **확률/조건:** 희귀 재료와 팁 확률은 데이터 테이블로 관리하고, 확률 합계 검증 기능을 에디터에 둔다.

## 7) 밸런스 및 난이도 분석

- **자원의 성장 방식:**
    - 신규 지역일수록 식물 내구도와 동물 이동 속도·내구도가 증가한다.
    - 내구도만 계속 높이지 않고 군집 간 거리, 장애물, 희귀 자원 위치로 동선을 어렵게 만든다.
    - 상위 지역의 재료는 더 높은 판매가의 메뉴에 사용되도록 해 난이도 상승의 보상을 보장한다.
- **시간 또는 스테이지 기반 난이도 변화:**
    - 수확 초반에는 낮은 내구도 자원을 배치해 즉시 쾌감을 제공한다.
    - 중반에는 고밀도 군집과 동물을 함께 배치해 경로 선택을 요구한다.
    - 종료 직전에는 희귀 자원 알림 등 선택 목표를 제시해 긴장감을 만든다.
    - 영업 초반은 단일 메뉴 주문 중심, 후반은 복수 메뉴와 성급한 손님 비율을 높인다.
- **플레이어 성장 속도와의 관계:**
    - 권장 장비 수준에서는 한 번의 수확으로 다음 영업에 필요한 핵심 재료를 확보할 수 있어야 한다.
    - 장비가 낮으면 재료 부족, 식당이 낮으면 주문 적체가 나타나도록 병목을 분리한다.
    - 한쪽 강화만으로 전체 효율이 무한히 증가하지 않도록 수확량과 식당 처리량의 균형을 유지한다.
- **핵심 밸런스 지표:**
    - 분당 자원 획득량
    - 수확 스테이지 내 미수확 자원 비율
    - 메뉴별 제작 가능 횟수와 품절률
    - 분당 주문 처리량 및 평균 대기 시간
    - 연속 서빙 평균 단계와 실패 원인
    - 1회 영업 순이익과 다음 강화까지 필요한 반복 횟수
- **초기 프로토타입 목표:**
    - 한 번의 수확과 한 번의 영업을 합쳐 5분 안팎의 짧은 세션으로 구성한다.
    - 첫 세션 안에 눈에 보이는 장비 또는 시설 강화를 최소 1회 제공한다.
    - 초반에는 품절보다 연속 수확·서빙 성공을 자주 보여주고, 이후 재고 선택의 중요도를 높인다.

## 8) 기술 분석

- **개발 환경 가정:** Unity 기반 3D 모바일 프로토타입
- **씬 구조:**
    - `Boot`: 저장 데이터 및 공통 매니저 초기화
    - `Restaurant`: 재고 확인, 메뉴 편성, 영업, 시설 강화
    - `Harvest`: 지역 로드, 자원 수확, 제한 시간 진행
    - `Result`: 수확 및 영업 정산
- **이동/입력 처리 방식:** Unity Input System의 `PlayerInput`과 `OnScreenStick`을 사용한다. 입력 벡터를 월드 이동 방향으로 변환하고 Rigidbody 기반으로 이동한다.
- **공격/수확 구조:** 회전하는 칼날의 Trigger Collider가 `IHarvestable` 인터페이스를 가진 대상에 일정 주기로 수확력을 적용한다. 시각적 회전 속도와 실제 판정 주기를 분리한다.
- **투사체 구조:** 기본 버전에는 투사체가 없다. 후속 장비가 추가되면 공통 `Projectile` 컴포넌트에 속도, 수명, 관통 수, 재타격 간격을 데이터로 주입한다.
- **스폰 매니저 구조:** `RegionData`를 읽는 `ResourceSpawnManager`가 자원 군집과 동물 활동 영역을 생성한다. 영업 씬은 `CustomerWaveData`에 따라 손님 큐를 만든다.
- **오브젝트 풀링 사용 여부:** 사용한다. 재료 파편, 획득 이펙트, 플로팅 텍스트, 손님, 음식 오브젝트처럼 반복 생성·제거되는 대상에 우선 적용한다.
- **ScriptableObject 사용 여부:** 사용한다. 지역, 자원, 레시피, 장비, 시설, 손님, 웨이브 등 변경이 적은 기획 데이터를 에셋으로 관리한다.
- **JSON 사용 여부:** 사용한다. 재고, 재화, 강화 레벨, 해금 상태, 옵션 등 런타임 저장 데이터는 버전 필드를 포함한 JSON으로 저장한다. ScriptableObject 에셋은 빌드 후 사용자 저장 파일 용도로 사용하지 않는다.
- **UI 구현 방식:** uGUI Canvas를 기본으로 사용하며, 화면 단위 Presenter가 게임 상태를 구독해 HUD를 갱신한다. 모바일 Safe Area와 해상도별 Canvas Scaler를 적용한다.
- **카메라 처리 방식:** 수확 씬은 플레이어를 따라가는 고정 각도 탑다운 카메라를 사용하고, 부드러운 추적과 맵 경계 제한을 적용한다. 레스토랑 씬은 전체 좌석과 주방이 보이는 고정 카메라를 우선한다.
- **성능 고려:**
    - 멀리 있는 자원의 애니메이션과 AI 업데이트 빈도를 낮춘다.
    - 수확 대상 탐색은 레이어 마스크와 공간 분할/범위 쿼리로 제한한다.
    - 재료 조각은 실제 물리 오브젝트 수를 제한하고 일부를 GPU 파티클로 대체한다.
    - 모바일 실기기에서 오브젝트 수, 드로우콜, GC 할당, 발열을 측정한다.

## 9) 프로토타입 우선순위

### 1차: 핵심 재미 검증

- 초원 1개 지역
- 밀과 소고기 자원
- 이동, 회전 칼날, 파괴, 드롭, 자동 흡수
- 빵과 스테이크 2개 메뉴
- 영업 전 조리, 주문 접수, 준비된 음식 서빙, 재료·요리 재고 차감, 매출 정산
- 장비 강화 2종과 식당 강화 2종

### 2차: 반복 루프 검증

- 추천 메뉴와 재고 기반 지역 선택
- 품절과 연속 서빙 보너스
- 직원 자동 서빙
- 신규 지역 1개 및 레시피 확장
- 저장/불러오기와 튜토리얼

### 3차: 콘텐츠 및 완성도 확장

- 초원·바다·숲 3개 지역
- 특수 동물 패턴과 희귀 재료
- 손님 유형, 시설, 메뉴 성장
- 진동, 사운드, 파티클, 카메라 연출 최적화
- 밸런스 지표 수집 및 난이도 조정
